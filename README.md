NextUp — Appointment & Queue Management System

NextUp is a web-based application that simplifies appointment booking and queue management for local businesses such as salons, clinics, and service centers.

Customers can book appointments, track their queue positions, and estimate waiting times. Businesses can manage services, staff, appointments, and walk-in customers through a centralized dashboard.

Features

- Appointment Management: Book, view, reschedule, and cancel appointments.
- Queue Management: Generate tokens for walk-in customers and manage queue status.
- Customer Tracking: View queue positions and estimated waiting times.
- Business Management: Manage business profiles, services, and operating hours.
- Staff Management: Manage staff members and assign services.
- Dashboard: View appointment and queue statistics.
- Authentication: Secure login with JWT-based authentication and role-based authorization.
- Email Notifications: Send appointment confirmations and cancellation notifications.

Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- Testing: Postman
- Notifications: Third-party Email API

Project Modules

1. Appointment Booking & Scheduling — Handles appointment creation, availability, rescheduling, and cancellation.
2. Queue Management & Customer Tracking — Handles walk-in registration, token generation, queue positions, and waiting-time estimation.
3. Business Administration & Staff Management — Handles business profiles, services, staff assignments, and dashboard statistics.

Getting Started

Prerequisites

- Node.js and npm
- MongoDB
- Git

Installation

1. Clone the repository:
   
   git clone <repository-url>

2. Navigate to the project directory:
   
   cd NextUp

3. Install dependencies for the frontend and backend according to the project structure.

4. Configure the environment variables in a ".env" file.

5. Start the backend and frontend development servers.

Team Responsibilities

The project is developed collaboratively, with each member responsible for a core module. Shared responsibilities include authentication, integration, testing, code reviews, documentation, and deployment.

Project Objective

To reduce waiting times, prevent appointment scheduling conflicts, and improve operational efficiency and customer experience for local businesses.
